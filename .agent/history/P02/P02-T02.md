- Date: 2026-10-11
- Model: sonnet (attempt 1)
- Cost: $0.49

## Summary
Preflight now installs missing project dependencies before a run: it uses commands.setup, or the standard command written back into project.yaml with a comment-preserving text edit. A missing system tool prints `FAIL  <tool> is not installed. Install it with: <hint>` and returns False without installing. Verified by three new tests with a fake npm on PATH (24 pass in tests/test_deps.py on Windows; 36 across deps, doctor and presets on WSL); ruff is clean.

## Acceptance criteria
- Node fixture with no node_modules/ and an empty commands.setup: preflight runs the fake `npm ci` once, writes `npm ci` into commands.setup, and the project.yaml comments are still present
- A second preflight on the same fixture runs nothing (the fake npm call log has one entry)
- With commands.setup set, preflight runs that command instead of the standard one
- With no npm on PATH, preflight prints the exact install command for Node and returns False without running anything

## Decisions
- install_deps(cfg) in cli.py runs after the agent CLI check; standard commands are de-duplicated, run one by one, and written to commands.setup as a JSON-style list by remember_setup (regex text edit, comments kept) — same approach as cmd_init
- When commands.setup is set it is run as is and never rewritten
