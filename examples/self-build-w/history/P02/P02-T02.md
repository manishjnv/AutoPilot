## Summary
Added `ap tour [--speed N] [--once]`. It reads the recording from `autopilot/templates/tour/`, builds dashboard data per second of recorded time, and draws it with `dash_term.frame`. At the end it prints PROOF.md and the two Install/Start lines. It skips project lookup and `remember()`, so it writes nothing. The 7 new tests in `tests/test_tour.py` pass. These include `--once` with an empty PATH and a temp home (exit 0, VERIFIED, install line, Not proven), nothing written to the work or home folder, and the packaged copy equal to `examples/tour`. The ruff gate is clean. One older test in that file, `test_make_tour_regenerates_the_same_file`, still fails on this Windows checkout: it compares bytes, and `examples/tour/events.jsonl` has CRLF line endings here. I did not touch it. The full suite was not run; a `-k "cli or help or reference"` subset passed.
