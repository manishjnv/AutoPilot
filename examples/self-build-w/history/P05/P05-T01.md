## Summary
Under git.mode: pr, a task with gate warnings or a criterion without a test now opens a draft PR with a `## Not proven` list in the body; a clean task opens a ready PR with 'Nothing'. The logic is task_not_proven in docs.py, reusing untested_criteria, wired into Orchestrator._merge_pr. Verified by 3 tests with a fake gh recorder plus ruff; direct mode is untouched.

## Acceptance criteria
- A task with a gate warning opens a draft PR whose body lists the warning under Not proven
- A clean task opens a ready PR, as before
- git.mode: direct is unchanged
