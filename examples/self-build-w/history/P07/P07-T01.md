## Summary
Added `ap audit --history [--days N] [--home PATH]` in the new autopilot/commands/audit.py, routed in cli.main before the project lookup so it needs no project and writes nothing. It counts sessions, tokens, tool calls and repeats (a Bash command failing 3 or more times in one session), prices retries at public rates and prints a table, a total line and 'Retries cost about $X of $Y.'. Three tests in tests/test_audit.py pass; ruff E9,F63,F7,F82 is clean. The full suite and the WSL script were not run.
