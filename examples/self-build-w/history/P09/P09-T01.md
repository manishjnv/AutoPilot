## Summary
Added a Stop hook to the plugin: `plugin/hooks/hooks.json` runs `plugin/scripts/seal.py` (python3, falling back to python). seal.py blocks "done" when the project test command fails or a changed test file has fewer lines than at HEAD, with at most 5 blocks per session. The 7 new tests in `tests/test_plugin_hook.py` pass on Windows Python and ruff is clean. I did not run the WSL script.
