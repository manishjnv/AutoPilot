## Summary

## Decisions
- docker_box.wrapped() gives each container a unique --name autopilot-<hex12> and always runs docker rm -f <name> on exit, because a killed docker client does not stop its container
- Container env comes from env_names(): SECRET_NAMES, every ANTHROPIC_*/CLAUDE_* variable, ENABLE_CLAUDEAI_MCP_SERVERS and the keys of agent.env, minus CLAUDE_CONFIG_DIR and the *_CLAUDE_BIN variables. Only names go in argv, never values
- Git dirs inside the worktree are not mounted again (they are already under /work)
- The OSError message of ClaudeCLIBackend now names cmd[0], so a missing docker binary says docker
