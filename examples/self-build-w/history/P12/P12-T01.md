## Summary
Added autopilot/backends/openai_compat.py: one non-streaming urllib POST to <base_url>/chat/completions with model_map, an optional Bearer key from agent.api_key_env, fenced `path:` file blocks written all-or-nothing after a path check, and the failure mapping set in ADR 0004. get_backend returns it and Config.validate accepts openai_compat. tests/test_openai_compat.py (15 tests, 127.0.0.1 http.server only) covers every criterion. The WSL suite gave 1031 passed, 1 skipped with three tests left out; those three also fail on unchanged HEAD.

## Acceptance criteria
- A canned answer with one fenced file block writes that file into the worktree and returns ok
- A 500 from the endpoint returns ok=False with infra network
- A path outside the worktree is refused
- config validation accepts agent.backend: openai_compat
- No real network in tests (only a 127.0.0.1 test server)
