## Gaps
- **Add pyproject.toml so the package is installable with a `todo` console script** [missing/low] The repo has no pyproject.toml or setup.py. The project goal describes a Python package, but it can only be used from the repo root via `python -m todo`. Add a PEP 621 pyproject.toml (setuptools backend) with name, version, requires-python>=3.8, packages=[todo], and a `[project.scripts] todo = "todo.cli:main"` entry. The `todo` script must return main()'s exit code (for example via sys.exit, or confirm the console-script wrapper handles it). Document `pip install .` in the README and add a CHANGELOG line.
- **Untrack build artifacts and extend .gitignore for Python** [bug/low] `git ls-files` lists tests/__pycache__/*.pyc, todo/__pycache__/*.pyc and run.out. .gitignore only covers AutoDev runtime files. Add `__pycache__/`, `*.pyc`, `.pytest_cache/`, `*.egg-info/`, `build/`, `dist/`, `todo.json` and `run.out` to .gitignore, and remove the already-tracked artifacts from the index (`git rm --cached`) or flag them for the orchestrator to untrack, since sessions must not run git commands.
